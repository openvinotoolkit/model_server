# Deploy Model Server

:::info Phase 1 structure note (pending stakeholder review)
Deployment-method chooser landing page.
:::


There are multiple options for deploying OpenVINO Model Server

1. [With Docker](docker.md) - use pre-built container images available on Docker Hub and Red Hat Ecosystem Catalog or build your own image from source.
2. [On baremetal Linux or Windows](baremetal.md) - download packaged binary and run it directly on your system.
3. [In Kubernetes](kubernetes.md) - use helm chart, Kubernetes Operator or OpenShift Operator.
